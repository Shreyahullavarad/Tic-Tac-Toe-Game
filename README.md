# 🎮 Tic Tac Toe Game (With AI)

This is a Tic Tac Toe game I built using Python and Tkinter.  
It supports both Human vs Human and Human vs AI modes.

I added an unbeatable AI using the Minimax algorithm and designed the interface to look clean and modern.

---

## ✨ Features

- Human vs Human mode  
- Human vs AI mode  
- AI uses Minimax algorithm (cannot be beaten)  
- Score tracking system  
- Restart board option  
- Reset score option  
- Simple dark theme UI  
- Sound effect on click  

---

## 🧠 About the AI

For the AI mode, I implemented the **Minimax algorithm**.  
It checks all possible future moves before deciding the best one.

Since Tic Tac Toe has limited board combinations, the algorithm can calculate the optimal move every time, which makes the AI unbeatable.

---

## 🛠 Technologies Used

- Python  
- Tkinter (for GUI)  
- Recursion  
- Basic game logic and state management  

---

## ▶ How to Run

Make sure Python is installed.

Run:

```bash
python TicTacToe.py
```
